# Short live demo and reflection

1. Open the public URL signed out. Explain: survive the sidewalk and beat your best distance.
2. Start, steer, show obstacles and distance, then demonstrate a lost life and restart after game over.
3. Show the GitHub build log and identify a real change made after a silent unfamiliar-user test.
4. Explain one code choice: collision grace period avoids repeated hits; delta-time movement avoids frame-rate-dependent speed; capped drift stays weaker than steering.
5. Close with one actual failure, diagnosis, revision, and lesson. Fill these from your own testing—not a hypothetical success story.

## Submission checklist

- [ ] Public URL works signed out.
- [ ] Public URL works on a second device.
- [ ] GitHub repository includes three game files and build log.
- [ ] User-test observation, revision, and retest are recorded.
- [ ] Student can explain core code and agent contribution.
- [ ] Live demo and reflection practiced.
